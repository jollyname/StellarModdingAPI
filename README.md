# StellarModdingAPI

A modding API for the game StellarDrive.

StellarModdingAPI is a plugin built with [MelonLoader](https://melonwiki.xyz/)
and provides tools for creating custom content for StellarDrive, including
custom parts, items, and Unity assets loaded from AssetBundles.

## Documentation

Full documentation, including guides and API references, is available here:

**[StellarModdingAPI Documentation](https://jollyname.github.io/StellarModdingAPI-Documentation/)**

This covers:

- Getting started (installing MelonLoader, setting up a mod project)
- Creating custom parts
- Loading and using custom assets

## Getting Started

To start building a mod with StellarModdingAPI, you can use the
[StellarDrive-ModTemplate](https://github.com/jollyname/StellarDrive-ModTemplate)
as a starting point.

See the [Getting Started guide](https://jollyname.github.io/StellarModdingAPI-Documentation/getting-started/)
in the documentation for full setup instructions.

## Features

- Create and register custom parts
- Define custom part properties and building costs
- Load custom Unity assets from embedded AssetBundles
- Extract asset keys automatically from constant fields
